## Features

- A clear hero with a "speak to a solicitor today" call to action
- **How we can help** service overview
- Client testimonials
- **Legal pages**: privacy policy, terms, and complaints procedure, which are
  important for regulated firms
- A responsive, accessible layout

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

```
index.html, privacy-policy.html, terms.html, complaints.html
styles.css, policy.css, main.js
```

## Run locally

```bash
git clone https://github.com/dean1234533/Woodgrange-Solicitors-.git
cd Woodgrange-Solicitors-
open index.html
```
